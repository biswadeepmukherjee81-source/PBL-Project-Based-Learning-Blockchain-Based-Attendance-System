# Blockchain-Based Attendance Management System with Performance Analytics

## 📌 Project Overview

This project is a learning-oriented blockchain-based attendance management system developed progressively through Project Based Learning (PBL).

The project explores the use of blockchain, smart contracts and performance analytics to create a more reliable, traceable and tamper-resistant approach to attendance record management.

The project was initially developed as a basic blockchain attendance prototype in PBL-2 and is being progressively enhanced in PBL-3 through improved UI/UX, performance analytics and preliminary Web3 experimentation.

---

## 🎯 Project Objective

The primary objective of this project is to practically explore blockchain technology by applying it to an attendance management use case.

The project focuses on:

- Understanding blockchain and smart contract concepts
- Developing attendance logic using Solidity
- Recording and analysing attendance data
- Exploring Web3 technologies for frontend-blockchain interaction
- Progressively developing the prototype into a more complete academic application

The initial prototype established the core technical foundation of the project.

The project is currently being enhanced with:

- Complete website UI/UX redesign

- ethers.js-based Web3 proof-of-concept

The current Web3 work is a preliminary learning and experimentation stage. Full integration of the attendance application with MetaMask, ethers.js and the smart contract is planned for the End-Term phase.

---

## ⚙️ Current System Workflow

The project follows the following conceptual workflow:

1. Attendance information is entered through the application interface
2. Attendance logic is processed using predefined rules
3. Smart contract logic is developed and tested using Solidity
4. Attendance data can be analysed to calculate attendance percentages
5. Web3 technologies are being explored for frontend-blockchain interaction
6. Full blockchain integration is planned as the next development phase

## 🔐 Smart Contract

The smart contract is written in Solidity and stored in `Attendance.sol`.

The contract contains the `AttendanceSystem` implementation used to explore attendance record management using smart contract logic.

The smart contract was developed and tested using Remix IDE as part of the project's initial technical foundation.

---

## 🌐 Web3 Proof-of-Concept

As part of PBL-3, a preliminary Web3 proof-of-concept has been developed to understand how a web application can interact with a blockchain wallet.

The current experimentation includes:

- Connecting a web application with MetaMask
- Accessing the connected wallet account
- Using ethers.js for blockchain-provider interaction
- Understanding the basic frontend → wallet → blockchain communication flow

### Current Web3 Flow

`Frontend → ethers.js → MetaMask`

### Planned End-Term Flow

`Attendance Application → ethers.js → MetaMask → Smart Contract → Blockchain`

The complete attendance application integration is planned for the End-Term phase.
